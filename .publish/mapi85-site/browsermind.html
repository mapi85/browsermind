Format JSON d'un outil custom

Un outil BrowserMind est un objet JSON décrivant ce que le LLM peut demander à l'extension de faire. La description est lue par l'IA — soyez précis.

ChampTypeStatutDescription
namestringrequisIdentifiant unique snake_case. Ex : extract_emails
iconstringoptionnelEmoji affiché dans l'interface. Ex : 📧
labelstringoptionnelNom court affiché dans la liste
descriptionstringrequisInstruction lue par le LLM — expliquez quand et comment utiliser l'outil
input_schemaobjectrequisJSON Schema des paramètres. Minimum : {"type":"object","properties":{}}
executorstringoptionnelinject · web_search_ext · generate_document_ext · api_call_ext
injectScriptstringsi injectFonction JS exécutée dans la page. Reçoit input, retourne un objet.

Exemple — Extracteur d'emails

{
  "name": "extract_emails",
  "icon": "📧", "label": "Extraire emails",
  "description": "Extrait tous les emails visibles sur la page courante.",
  "input_schema": { "type": "object", "properties": {}, "required": [] },
  "executor": "inject",
  "injectScript": "const m=[...document.body.innerText.matchAll(/[\\w.-]+@[\\w.-]+\\.[a-z]{2,}/gi)].map(m=>m[0]); return {emails:[...new Set(m)]};"
}

Exemple avec paramètres — Recherche ciblée

{
  "name": "search_and_summarize", "icon": "🔍", "label": "Rechercher",
  "description": "Recherche un terme sur DuckDuckGo et retourne les résultats.",
  "input_schema": {
    "type": "object",
    "properties": {
      "query": { "type": "string", "description": "Termes à rechercher" },
      "max_results": { "type": "number" }
    },
    "required": ["query"]
  },
  "executor": "web_search_ext"
}
Registre distant

Partager vos outils

📡 Registre distant — principe

Publiez un fichier JSON sur votre site. Vos utilisateurs le chargent en une URL, sans réinstaller l'extension. Vous mettez à jour le fichier, ils récupèrent les nouveaux outils au prochain démarrage.

1
Créez browsermind-tools.json avec votre tableau d'outils
2
Publiez-le avec le header Access-Control-Allow-Origin: *
3
BrowserMind → Config → Outils → URL → ↻ Charger
4
Les outils sont mis en cache local et rafraîchis à l'ouverture
// Structure attendue
{
  "version": "1.0", "author": "votre-nom",
  "tools": [ { /* outil 1 */ }, { /* outil 2 */ } ]
}
